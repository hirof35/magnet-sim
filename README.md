Magnet Simulator
ブラウザ上で動作する、物理演算に基づいたインタラクティブな磁石シミュレーターです。マウスで磁石を動かし、ボールに対して「引力」と「斥力」を適用して遊ぶことができます。

概要
技術スタック: TypeScript, Three.js, Vite

主な機能:

マウス追従による磁石操作

リアルタイムでの磁力調整（スライダー）

N極/S極（引力/斥力）のモード切替

インストールと実行方法
リポジトリの準備:
Node.js がインストールされている環境で、プロジェクトフォルダに移動します。

依存関係のインストール:

Bash
npm install
開発サーバーの起動:

Bash
npm run dev
ブラウザで表示された URL（通常は http://localhost:5173/）にアクセスします。

操作方法
磁石の移動: マウスを動かすと、画面上の磁石がマウスに追従します。

磁力の調整: 右上のスライダーを左右にドラッグして、磁力の強さを変更できます。

モード切替: ボタンをクリックすることで、「Attract (引力)」と「Repel (斥力)」を切り替えることができます。

実装の仕組み
本シミュレーターでは、ベクトル演算を用いて物理法則を模倣しています。

物理モデル: ボールの速度（Velocity）に対し、磁石との距離に基づいて計算した力（Force）を毎フレーム加算しています。

座標変換: Vector3.unproject メソッドを使用し、2D画面上のマウス座標を3D空間上の座標へ正確に変換しています。
